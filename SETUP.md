# Install your GitHub portfolio

1. Extract this ZIP on your computer.
2. Open https://github.com/HashmathAl-Hazan/HashmathAl-Hazan .
3. Replace the existing README.md with this README.md. Upload the entire assets folder at the repository root, alongside README.md. Do not upload the ZIP itself or place these files inside an extra parent folder.
4. Commit the changes and open https://github.com/HashmathAl-Hazan .

You only need README.md and assets/ on GitHub. SETUP.md and preview files are for your reference.

The banner, reveal effect, floating terminal, project frames, buttons and technology icons are included locally. No API key, package installation or GitHub Actions workflow is required. Uploading README.md alone will leave the local artwork missing.

The three GitHub statistics graphics use a public third-party service. They were checked when this package was prepared, but may become unavailable or rate-limited later. If that happens, remove the three external image tags under My GitHub activity; all the custom artwork will continue to work.

This uses animated SVG images. It does not embed a live 3D application or run JavaScript on your GitHub profile. Some viewers may show static frames.

Name, email, GitHub username and portfolio links were taken from the details you shared. LinkedIn uses the link currently visible on your GitHub profile. All project links can be edited directly in README.md.

Use only the icons that reflect your own experience. No skills percentage or invented performance metric has been added.

CareerDesk was not publicly accessible when checked, so its card opens an email enquiry. If you make its repository or demo public, replace the two CareerDesk mailto links in README.md with that URL. CogniCare links to your publicly available contribution showcase.
